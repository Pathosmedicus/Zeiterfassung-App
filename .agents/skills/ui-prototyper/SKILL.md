# UI / Tailwind Prototyper Skill

Dieser Skill stellt sicher, dass Interfaces modern, ästhetisch ansprechend, responsiv und visuell überprüft sind.

## Design-Prinzipien:

1. **Erstklassige Ästhetik:**
   - Harmonische Farbpaletten (z. B. HSL-basierte Farben, abgestimmte Dark- und Light-Themes).
   - Klare Typografie (z. B. Inter, Roboto oder System-Fonts) mit stimmiger Hierarchie.
   - Weiche Schatten, subtile Glaseffekte (Glassmorphism) und konsistente Abstände (Spacing).
   - Mikro-Interaktionen: Hover-Effekte, weiche Übergänge (`transition`), aktive Zustände.

2. **Responsive Layouts:**
   - Mobile-First oder sauberes Flexbox-/Grid-Design, das auf allen Bildschirmgrößen gut lesbar bleibt.

3. **Visuelle Prüfung:**
   - Nutze den Browser-Subagenten (`browser_subagent`), um Webseiten zu öffnen, Screenshots zu prüfen und sicherzustellen, dass keine Darstellungsfehler vorliegen.
