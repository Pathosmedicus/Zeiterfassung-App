# README Generator Skill

Dieser Skill erstellt oder aktualisiert eine ansprechende, klare und vollständige `README.md` für das aktuelle Projekt.

## Arbeitsablauf:

1. **Projektstruktur analysieren:**
   - Untersuche den Projektordner (z. B. `index.html`, `package.json`, Quellcode-Ordner).
   - Identifiziere Technologien, Abhängigkeiten und Hauptfunktionen der Anwendung.

2. **Dokumentation aufbauen:**
   - **Titel & Kurzbeschreibung:** Worum geht es in diesem Projekt? Welches Problem löst es?
   - **Features:** Aufzählung der Kernfunktionen mit kurzen Erklärungen.
   - **Technologie-Stack:** Verwendete Bibliotheken, Frameworks oder Standards.
   - **Installation & Schnellstart:** Schritt-für-Schritt-Anleitung, wie ein Anfänger das Projekt lokal öffnen oder starten kann.
   - **Projektstruktur:** Übersicht über die wichtigsten Ordner und Dateien.

3. **Verständlichkeit:**
   - Schreibe klar und übersichtlich mit Formatierungen (Badges, Listen, Code-Blöcke).
   - Halte die Erklärungen verständlich auch für Einsteiger.
